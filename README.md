# Bài tập lớn – Phân tích dữ liệu và trực quan hóa

Repository này chứa dữ liệu và mã nguồn phục vụ bài tập lớn
phân tích dữ liệu khí tượng – viễn thám và dự báo hạn hán, ngập lụt
cho tỉnh Long An.

## Nội dung chính
- Xử lý dữ liệu mưa và NDVI
- Tính chỉ số hạn khí tượng SPI-3M
- Phân tích thống kê SPI–NDVI
- Dự báo bằng mô hình SARIMA
- Trực quan hóa bằng Power BI và Power Apps

## Ghi chú
Các file được đặt trong cùng một thư mục để đảm bảo
khả năng chạy ổn định của mã nguồn.
